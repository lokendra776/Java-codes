# Java Codes Repository

This repository contains various Java programs and algorithms organized into different categories. The codes cover fundamental concepts, data structures, and algorithms, making it a useful resource for learning and reference.

## Folder Structure

The repository is organized as follows:

- **array and arraylist/**
  - **binary search/**
    - `basicbinarysearchcode.java`: Implementation of basic binary search algorithm.
  - **linear search/**
    - `leetcode01_evendigits.java`: Solution for finding even digit numbers.
    - `leetcode02_richestperson.java`: Solution for finding the richest person.
    - `min_in_array.java`: Program to find the minimum element in an array.
    - `searchin2Darray.java`: Implementation of search in a 2D array.
    - `searching_char_instring.java`: Program to search for a character in a string.

- **basic and important code/**
  - `armstrongno.java`: Check if a number is an Armstrong number.
  - `counttarget.java`: Count occurrences of a target number.
  - `fibonacci.java`: Generate Fibonacci series.
  - `largestamong3.java`: Find the largest among three numbers.
  - `primewithfunction.java`: Check for prime numbers using functions.
  - `reversethedigit.java`: Reverse the digits of a number.
  - `starpattern.java`: Print star patterns.
  - `swap.java`: Swap two numbers.
  - `takeinputsinglecharacter.java`: Take input of a single character.

- **Java_Complete_Notes/**
  - **Chapter 0/**: Introduction to Java.
  - **Chapter 1/**
    - `marks_calculator.java`: Program to calculate marks.
    - `three_number_sum.java`: Calculate the sum of three numbers.
  - **Chapter 2/**
    - `ch2_01.java`: Various examples from Chapter 2.
    - `expression.java`: Evaluate expressions.
    - `number.java`: Number-related programs.
  - **Chapter 6/**
    - `pr_01.java`: Practice problems from Chapter 6.
  - **Chapters 3-5, 7-15/**: Additional notes and examples.

## Usage

To run any of the Java programs, follow these steps:

1. Ensure you have Java Development Kit (JDK) installed on your machine.
2. Open a terminal or command prompt.
3. Navigate to the directory of the desired program.
4. Compile the Java file using the command:
   ```bash
   javac filename.java
   ```
5. Run the compiled program using the command:
   ```bash
   java filename
   ```
